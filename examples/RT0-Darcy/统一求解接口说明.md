# RT0 统一求解接口

在本目录运行，需要 NumPy 和 SciPy：

```python
import numpy as np
from rt0_darcy_2d import rectangle_mesh, solve_rt0

result = solve_rt0(rectangle_mesh(16), element="RT0", dim=2, refinements=0,
                  source=lambda x, y: 2*np.pi**2*np.sin(np.pi*x)*np.sin(np.pi*y))
print(result["P"], result["Q"], result["conservation"])
```

- `mesh=(nodes,cells)`：也可直接输入已有网格，包括逐级加密后的网格。
- `refinements=0`：非负整数，默认不加密；二维每加密一次，单元数乘 4，保留旧节点并追加中点。三维目前只支持 0。显式边界面编号必须使用加密后最终网格的编号。
- `dim=2/3`：分别要求三角形/四面体；三维网格需自行提供。
- `element="RT0"`：当前仅实现 RT0-P0，不接受其他元。
- `permeability`：正标量或常值对称正定矩阵；尚不支持空间变化的系数。
- `source`：常数或 `f(x,y[,z])`。
- `pressure`：边界压力，默认 0；常数或 `g(x,y[,z])`。
- `noflow_edges`：不透水边界面编号列表，默认空；其余边界面默认给压力。
- `pressure_edges`：可显式指定压力边界；它与不透水边界必须不重叠且覆盖全部边界。

`result` 返回压力 `P`、全局法向积分通量 `Q`、网格、`facets` 和逐单元积分守恒残差最大值。
边编号由 `result["facets"]["edge_nodes"]` 给出；默认按端点编号排序生成，不等于旧详解版的首次遍历编号。
如需先查看边编号以选择混合边界，可先调用 `solve_rt0(mesh)` 并检查其 `facets`。

所有求解代码均位于 `rt0_darcy_2d.py`，无需独立求解器文件。

批量算法通过单纯形的一、二阶几何矩精确计算常系数质量矩阵，COO 一次构造全局稀疏矩阵，重复位置自动累加。
源项使用 Duffy 变换与每维四点 Gauss 规则；不再使用详解版的七点规则，非多项式源项会有微小求积差异。
压力边界用边/面重心求积，对仿射压力精确；更复杂边界数据可能需要更高阶边界求积。
当前只支持零法向通量的本质边界，不支持非零给定流量或纯 Neumann 问题。

`rt0_darcy_2d.py` 内的 `assemble` 已转调本文件内的批量接口，保留旧边编号；默认 `main()` 是简短求解示例。
