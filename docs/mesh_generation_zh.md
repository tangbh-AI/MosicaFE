# 高效网格生成代码说明

所有原有 `Mesh.xxx(...)` 接口继续使用，不需要另建主程序。

## 单文件如何组织

| `core/mesh.py` 内的部分 | 职责 |
| --- | --- |
| `Mesh` 类 | 对外工厂接口、节点和单元存储、方向整理、细化参数 |
| 公共数组工具与规则网格生成 | 规则网格的批量坐标、连接表及参数检查 |
| 二维、三维 Voronoi 生成 | Voronoi 几何、顶点去重和共享面整理 |
| 混合多边形、多面体生成 | 三角形合并、邻接关系、三维挤出与分锥 |

以上实现均在同一个文件 `core/mesh.py` 中。`Mesh.xxx()` 直接调用本文件后部的
数组生成函数，不再从 mesh_arrays、polyhedral 或 meshgen 文件导入。
基础几何工具继续复用 `core/utils.py`；Voronoi 所需 SciPy 仍按需导入。

`nodes[i]` 是全局节点 i 的物理坐标；`elements[c]` 是单元 c 使用的全局节点编号。
三维 `faces[c][f]` 是单元 c 第 f 个面的**局部**顶点编号，因此
`elements[c][faces[c][f]]` 才对应这张面的全局节点。
这些几何顶点不是高阶 VEM 的全部自由度；边点、面矩和体矩由空间层另外建立。

## 每一种网格怎样生成

### 1. interval：相邻编号批量配对

`linspace(a,b,nx+1)` 一次生成所有节点；`column_stack((arange(nx),arange(1,nx+1)))`
将左、右端点编号并排放置，得到 `(nx,2)` 连接表。没有逐单元循环。

### 2. rectangle：四个切片取出全部小格

`meshgrid` 建立 `(ny+1,nx+1)` 坐标阵列；`ravel` 按行展平。
`ids[:-1,:-1]`、`ids[:-1,1:]`、`ids[1:,1:]`、`ids[1:,:-1]`
依次代表所有小格的左下、右下、右上、左上顶点。
`stack(...,axis=-1)` 合成 `(ny,nx,4)`，再 reshape 成 `(nx*ny,4)`。
三角形用 `[[0,1,2],[0,2,3]]` 模板同时拆分全部四边形，得到 `(2*nx*ny,3)`。
节点编号、边界位置和原结构网格接口保持一致。

### 3. box：八个切片和四面体模板

三维 `meshgrid(indexing='ij')` 保持 x、y、z 数组轴顺序，展平时 z 下标变化最快。
八个切片取出每个小长方体的八角点。transpose 保持原来 k→j→i 的单元顺序。
六面体直接使用八角点表；Kuhn 模板把每格批量拆成六个四面体。
center 模式一次计算全部中心，通过十二个边界三角形模板得到十二个四面体。
`broadcast_to` 只是中心编号的广播视图，最终 concatenate 时才分配连接表。
Mesh 构造时批量计算行列式并统一四面体方向。

### 4. pentagon：共享中点去重和奇偶掩码

先生成基础四边形。`divmod` 同时计算所有单元的行列号，`(i+j)%2` 决定插入上边中点或下边中点。
一条水平边用 `行号*nx+列号` 唯一标识。`unique` 一次合并公共边中点，
`return_inverse` 将各单元映射到共享中点编号。
`where` 同时选择上下边的两种五顶点模板。这里的五顶点单元含共线边点。

### 5. voronoi_polygon：批量镜像、去重和一次单元遍历

随机种子只生成一次；每个种子沿四条边分别镜像，输入规模为 5N，
不再建立 9N 的组合镜像。自身种子的镜像把原单元限制在矩形内，
其他种子的镜像在盒内不会比其原点更近，因此无需组合反射。
几何计算交给 SciPy/Qhull；盒内顶点归一化后批量去重，建立旧→新编号。
仅遍历每个变长单元一次，用极角数组排序恢复边界环，最后删除孤立节点。

### 6. voronoi_polyhedron：公共面只构造一次

三维对六个边界平面分别镜像，输入规模为 7N，替代 27N 的组合镜像。
批量过滤掉只属于镜像种子的面。两种子连线给出公共面的法向，
删除法向绝对值最大分量所在的坐标轴，得到稳定二维投影，再按极角排序。
这样避免每个面执行 SVD。面只排序一次，并直接登记给两侧原单元。
最后每个体单元整理一次顶点集合，`unique(return_inverse=True)` 把全局面编号转换成局部编号。

### 7. mixed_polygon：批量基础网格，局部顺序合并

基础四边形、内部点扰动、随机对角线模板均批量生成。
将三角形边的两个端点排序，消除方向差异，再按端点对进行 lexsort。
基础剖分一条边最多出现两次，因此排序后相同的相邻记录就是公共边；
记录编号整除 3 得到所属三角形，从而建立 `(三角形数,3)` 邻接表。

合并本身存在状态依赖，保留必要迭代：遍历未占用的起始三角形，维护局部前沿，
尝试合并相邻三角形。公共反向边消去后必须形成唯一边界环。
`_admissible` 检查顶点均值是否严格处于每条有向边的左侧，保证星形核条件；
`concave=False` 时另外检查凸性。最后批量删除被合并吞掉的孤立节点。
max_sides 固定时局部几何规模受限；全局邻接排序约为 O(N log N)。

### 8. mixed_polyhedron：批量层节点、批量中心、复用面模板

`tile` 复制二维节点，`repeat` 配上各层 z 坐标。
一次生成分锥选择掩码并预分配全部节点内存，分段 reduceat 求每个底面的顶点均值，
再批量填入所有选中母单元的中心。每个母单元只遍历一次来组织变长连接关系。
相同边数的棱柱、棱锥复用缓存的局部面模板。
分锥仅在母单元内部增加三角面，母单元公共面保持完整，避免悬挂边面。
三角形底面的棱锥就是四面体。

### 9. from_arrays：直接接收已有连接表

等长整数 ndarray 走快速路径，不重复逐行转换；变长列表仍逐条整理以兼容现有接口。
二维单元方向通过扁平编号、分段鞋带公式统一计算；三维四面体用批量行列式检查方向。
自定义混合网格应显式指定 polygon 或 polyhedron；当前自动类型推断只查看首个单元。

## 常见数组操作是什么意思

| 操作 | 在本项目中的用途 |
| --- | --- |
| `meshgrid` | 由各方向坐标生成规则节点阵列 |
| `stack/column_stack` | 将不同角点或坐标分量合成连接表、坐标表 |
| `reshape/ravel` | 在网格阵列与逐单元二维表之间转换形状 |
| `unique(...,return_inverse=True)` | 批量去重并生成全局编号映射 |
| `lexsort` | 按边的两个端点排序，批量找到相同公共边 |
| `reduceat` | 按变长单元或面的分段起点批量求和 |
| `broadcast_to` | 复用相同编号或坐标，不先显式复制重复数据 |
| `tile/repeat` | 为挤出网格复制平面节点及层高 |

## 循环与性能的实际含义

规则网格的数组生成函数零个显式 for；Voronoi、混合网格的每个生成或辅助函数
最多一个显式 for，没有函数内嵌套 for。整个流程仍存在多层逻辑遍历，
例如母单元遍历调用面的处理函数；map、NumPy、SciPy 也会执行内部迭代。
性能收益来自批量数组、减少镜像规模、减少排序、复用模板和预分配内存，
并非把循环拆成函数就自动变快。大规模三维网格需要留意数组峰值内存。

## 使用方式

```python
from MosicaFE import Mesh
mesh = Mesh.rectangle(nx=32, ny=32, element_type='triangle')
# 或 Mesh.box(...), Mesh.pentagon(...), Mesh.voronoi_polygon(...),
# Mesh.voronoi_polyhedron(...), Mesh.mixed_polygon(...), Mesh.mixed_polyhedron(...)
```

固定 seed 可以复现当前实现的随机网格；批量去重可能改变旧版本的全局节点编号，
固定 seed 不代表与所有历史版本的数组逐项相同。
生成器仍要求合法星形单元、三维面共面，不支持任意非星形单元或曲面面片。
